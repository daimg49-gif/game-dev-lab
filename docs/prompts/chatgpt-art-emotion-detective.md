# 給 ChatGPT 的生圖指令：《情緒偵探社》v1

共 4 張圖。每張圖都是**先貼「共同風格」，再貼該張圖的指令**，一張一張生。

做好的圖存在遊戲 repo `daimg49-gif/emotion-detective` 的 `assets/raw/`，檔名照下表。Claude 會負責去背、縮放、調色後放進遊戲。

| # | 檔名 | 用在哪 | 尺寸 |
|---|---|---|---|
| 1 | `title.png` | 開始畫面主視覺 | 橫式 16:9 |
| 2 | `monster-angry.png` | 闖關：生氣怪，3 個動作 | 橫式 3:1 |
| 3 | `monster-frustrated.png` | 闖關：挫折怪，3 個動作 | 橫式 3:1 |
| 4 | `stage-bg.png` | 闖關背景，可左右無縫重複 | 橫式 3:1 |

人物、地圖、圖示由 Claude 用程式畫，不需要生圖。

## 共同風格（每張圖都先貼這段）

```
請幫我畫一張像素風（pixel art）遊戲美術，用在給台灣國小三到六年級學生玩的教育遊戲《情緒偵探社》。

風格規定：
- 復古 16-bit 像素風，像素格清楚，邊緣銳利，不要模糊、不要漸層柔化（no anti-aliasing）
- 每個物件有 1 像素深色外框
- 色彩溫暖、明亮、可愛，不恐怖、不暴力
- 盡量只用這組配色：#2B2D42 深藍黑、#8D99AE 灰藍、#EDF2F4 米白、#EF233C 紅、#F4A261 橘、#E9C46A 黃、#2A9D8F 綠、#7B6D8D 灰紫、#F2B5D4 粉
- 畫面裡不要有任何文字、字母、數字、浮水印、簽名
- 不要出現任何現有卡通、電影或遊戲的角色，全部原創
```

## 圖 1：`title.png`

```
畫一張遊戲開始畫面的主視覺，橫式 16:9。

場景：黃昏的國小校園中庭，有一棟兩層樓的教室，一樓有一扇掛著放大鏡標誌的門（偵探社社辦）。
前景：一位國小學生偵探站在中間，手拿放大鏡，戴著小小的偵探帽，表情好奇。
身邊飄著 4 顆小小的情緒光球：紅色（生氣）、藍色（難過）、黃色（開心）、灰紫色（害怕），每顆光球有簡單的表情。
畫面上方三分之一留空，給遊戲標題文字使用（不要畫字）。
```

## 圖 2：`monster-angry.png`

```
畫一隻原創的「生氣怪」，是遊戲裡代表生氣情緒的小怪物，可愛不恐怖。
外型：紅色、方塊形的軟軟果凍身體，頭頂有像火苗的尖角，眉毛倒豎，嘴巴緊閉。

請把同一隻怪物畫成 3 個動作，由左到右排成一橫排，3 格一樣大，格子之間留寬空白，彼此不要重疊：
1. 平常：站著，微微生氣
2. 膨脹：身體變大一倍，頭頂冒煙，臉更紅
3. 冷靜：身體縮小一半，顏色變成淡粉紅，眉毛放平，閉眼

3 個動作必須是同一隻怪物，造型、比例、配色一致。
背景用透明；如果做不到透明，請用純洋紅色 #FF00FF 平塗背景，不要有陰影或地板。
```

## 圖 3：`monster-frustrated.png`

```
畫一隻原創的「挫折怪」，是遊戲裡代表挫折情緒的小怪物，可愛不恐怖。
外型：灰紫色、像一團打結的毛線球，身上有好幾個糾纏的結，兩隻小眼睛皺著，嘴巴歪一邊。

請把同一隻怪物畫成 3 個動作，由左到右排成一橫排，3 格一樣大，格子之間留寬空白，彼此不要重疊：
1. 平常：浮在空中，看起來很煩
2. 打結：身上的結變多、變緊，體積變大，擋住去路的樣子
3. 解開：毛線鬆開變成一條柔軟的線，表情放鬆，顏色變亮

3 個動作必須是同一隻怪物，造型、比例、配色一致。
背景用透明；如果做不到透明，請用純洋紅色 #FF00FF 平塗背景，不要有陰影或地板。
```

## 圖 4：`stage-bg.png`

```
畫一張橫向捲軸遊戲的背景，橫式 3:1。

場景：從側面看的國小校園走廊外牆和操場遠景，黃昏天空，遠方有樹和山的剪影。
這張只當背景，所以：
- 不要有人物、怪物
- 畫面下方四分之一保持簡單的單色地面，遊戲會在上面另外畫平台
- 左邊邊緣和右邊邊緣要能無縫接起來，可以左右重複拼接
- 顏色比前景稍微淡一點、對比低一點，讓角色在上面看得清楚
```

3. 上傳到 `emotion-detective` repo 的 `assets/raw/`，或直接傳到 Claude 的對話裡由 Claude 上傳
