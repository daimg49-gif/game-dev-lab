做好的圖上傳到遊戲 repo `daimg49-gif/emotion-detective` 的 `assets/raw/ch1/`，檔名照下表。Claude 會負責去背、裁切、縮放、調色後放進遊戲。

## 共同風格（每張圖都先貼這段）

```
請幫我畫一張像素風（pixel art）遊戲美術，用在給台灣國小三到六年級學生玩的教育遊戲《情緒偵探社》。

風格規定：
- 復古 16-bit 像素風，像素格清楚，邊緣銳利，不要模糊、不要漸層柔化（no anti-aliasing）
- 每個物件有 1 像素深色外框
- 色彩溫暖、明亮、可愛，不恐怖、不暴力
- 盡量只用這組配色：#2B2D42 深藍黑、#8D99AE 灰藍、#EDF2F4 米白、#EF233C 紅、#F4A261 橘、#E9C46A 黃、#2A9D8F 綠、#7B6D8D 灰紫、#F2B5D4 粉
- 畫面裡不要有任何文字、字母、數字、浮水印、簽名
- 不要出現任何現有卡通、電影或遊戲的角色，全部原創
- 跟第三章已經畫好的「生氣怪」（紅色果凍方塊、頭頂火苗）和「挫折怪」（灰紫色毛線球）是同一個系列，畫風、線條粗細、可愛程度要一致
```

## 圖 1：`monster-excited.png`

```
畫一隻原創的「興奮怪」，是遊戲裡代表「興奮」的小怪物，可愛不恐怖。外型：橘色、圓滾滾的彈跳球，身上有黃色星星花紋，眼睛亮晶晶、嘴巴大大地笑。

請把同一隻怪物畫成 3 個動作，由左到右排成一橫排，3 格一樣大，格子之間留寬空白，彼此不要重疊：
1. 平常：微微彈起來，開心地笑
2. 狂跳：身體被拉長成橢圓形，跳得很高，周圍噴出小星星，表情有點失控
3. 慢下來：身體變回圓圓的、坐在地上，閉著眼睛微笑

3 個動作必須是同一隻怪物，造型、比例、配色一致。
背景用透明；如果做不到透明，請用純洋紅色 #FF00FF 平塗背景，不要有陰影或地板。
```

## 圖 2：`monster-proud.png`

```
畫一隻原創的「得意怪」，是遊戲裡代表「得意」的小怪物，可愛不恐怖。外型：金黃色的氣球，下巴抬得很高、鼻子翹翹的，頭上一個小小的紙皇冠。

請把同一隻怪物畫成 3 個動作，由左到右排成一橫排，3 格一樣大，格子之間留寬空白，彼此不要重疊：
1. 平常：浮在空中，眼睛半閉、嘴角往一邊翹
2. 膨脹：氣球變大一倍，下巴抬得更高，擋住整個畫面的感覺
3. 消氣：縮小成一半，皇冠歪掉，表情有點不好意思，臉頰紅紅的

3 個動作必須是同一隻怪物，造型、比例、配色一致。
背景用透明；如果做不到透明，請用純洋紅色 #FF00FF 平塗背景，不要有陰影或地板。
```

## 圖 3：`stage-bg.png`

```
畫一張橫向捲軸遊戲的背景，橫式 3:1。

場景：從側面看的國小園遊會，白天，攤位上掛著彩旗和氣球，遠方是校舍和藍天白雲。
這張只當背景，所以：
- 不要有人物、怪物
- 畫面下方四分之一保持簡單的單色地面，遊戲會在上面另外畫平台
- 左邊邊緣和右邊邊緣要能無縫接起來，可以左右重複拼接
- 顏色比前景稍微淡一點、對比低一點，讓角色在上面看得清楚
```
