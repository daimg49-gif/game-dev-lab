## 序章：偵探社第一天（教學，約 2 分鐘）

場景：偵探社社辦。

> **米亞**：你就是新社員？歡迎！我們偵探社不找失物，我們找的是心情。
> **米亞**：學校裡每天都有人不對勁。有人生氣、有人難過，可是他們很少直接說出來。
> **米亞**：偵探要做三件事：找線索、說出那是什麼情緒、陪他找到適合的方法。

**教學操作**（畫面提示，一次一步）：

1. 用左下方向鍵走到書架 → 點「調查」→ 拿到「情緒圖鑑」
2. 走到米亞旁邊 → 點「說話」

> **米亞**：線索有四種：看**表情**、看**身體**、聽他**說的話**、看**周圍發生什麼事**。
> **米亞**：至少找到兩種線索，才能判斷是什麼情緒。找越多，判斷越準。
> **米亞**：今天有三個委託。公布欄上有，自己去看吧！

解鎖技能：**深呼吸**（闖關用，米亞送的第一招）

> **米亞**：送你第一招。不管遇到什麼事，先吸氣數到四，再慢慢吐氣。

## 案件 1：操場「不公平的出局」

**委託單**（公布欄）：操場躲避球比賽吵起來了。四年級的大熊一直站在場邊不走。

**開場**（兩種版本隨機出現一種）

### 線索

| 線索 | 版本 A | 版本 B |
|---|---|---|
| 表情 | 眉頭皺成一團，牙齒咬得很緊，臉漲紅 | 嘴巴噘著，眼睛一直盯著地上 |
| 身體 | 雙手握拳，肩膀一直在抖，站著不動 | 坐在場邊，腳一直踢地上的小石頭 |
| 話語 | 大聲：「他明明沒打到我！」 | 小聲：「每次都判我出局……」 |
| 情境 | 計分板：紅隊 9、藍隊 10，大熊是紅隊 | 同左 |
| 情境 | 籃球架旁的公告：「裁判的判決為最後判決」 | 同左 |

### 命名

- 最貼切：**不公平**
- 也算對：**生氣**
- 強度：版本 A 是 5，版本 B 是 3（差 1 以內都算對）

命名錯的時候大熊會說：

- 選「難過」：「我才沒有難過！我是覺得他亂判！」
- 選「丟臉」：「被判出局又不丟臉，是他判錯。」

### 陪伴

| 選項 | 方法 | 版本 A（強度 5） | 版本 B（強度 3） |
|---|---|---|---|
| 「我們先去樹下喝口水，等一下再說。」 | 先離開一下 | **很適合**：他跟你走到樹下，喝了兩口水，肩膀不抖了。他說：「球真的只擦到衣服。」 | **還可以**：他跟著走，但說：「我又沒有很氣。」 |
| 「你覺得哪裡不公平？跟我說說看。」 | 說出感受 | **不適合**：他吼：「就是不公平啊！」旁邊的人都轉頭看過來。 | **很適合**：他說上一場也被判過一次。講完以後，他不再踢石頭了。 |
| 「比賽而已，不要那麼生氣啦。」 | 硬吞下去 | **不適合**：他瞪你一眼，把球用力踢出場外。 | **不適合**：他說「喔」，然後不講話了。 |
| 「我陪你去問小翔，他看到什麼。」 | 處理原因 | **不適合**：大熊一走過去就開始大聲講，小翔也生氣了。 | **還可以**：小翔說球擦到他的袖子。大熊不太服氣，但點了點頭。 |

解鎖技能：**暫停**（陪伴選到「很適合」就解鎖；沒選到的話，結案時米亞補教）

> **米亞**：很氣的時候，先讓身體停下來。腳停住、手放開，數兩秒。

## 案件 2：教室「倒了三次的塔」

**委託單**：三年級教室，阿樂的紙塔一直倒，下課前要交。

### 線索

| 線索 | 版本 A | 版本 B |
|---|---|---|
| 表情 | 眼眶有點紅，嘴巴抿成一條線 | 沒什麼表情，眼睛看著窗外 |
| 身體 | 把紙揉成一團，用力丟進垃圾桶 | 趴在桌上，手指一直敲桌面 |
| 話語 | 「我就是很笨，做不起來啦！」 | 隔壁同學說：「他從第二節就一直在弄這個。」 |
| 情境 | 垃圾桶裡有三個揉爛的紙塔 | 同左 |
| 情境 | 黑板上寫著「下課前交作品」 | 同左 |

### 命名

- 最貼切：**挫折**
- 也算對：**生氣**
- 強度：版本 A 是 4，版本 B 是 3

命名錯的時候阿樂會說：

- 選「不公平」：「沒有人害我啊……是我自己做不好。」
- 選「緊張」：「我不是緊張，是一直失敗很煩。」

### 陪伴

| 選項 | 方法 | 版本 A（強度 4） | 版本 B（強度 3） |
|---|---|---|---|
| 「先去走廊走一圈，等一下再回來。」 | 先離開一下 | **很適合**：走回來以後，他把揉爛的紙攤開來看。 | **還可以**：他走了一圈，但看了時鐘：「沒時間了啦。」 |
| 「我們拆成三步，這次只做底座就好。」 | 把問題拆小 | **還可以**：他說「做了也是倒」，但還是拿了一張新的紙。 | **很適合**：他做好底座，自己說：「好像比較穩了。」 |
| 「倒三次也是收集資料。你看它每次從哪裡倒？」 | 換個角度想 | **不適合**：「我不想看！」他把頭轉開。 | **很適合**：他翻出垃圾桶的紙塔，發現三次都從左下角倒。 |
| 「你那麼聰明，一定做得到！」 | 打氣 | **不適合**：「可是就做不到啊！」他眼淚掉下來。 | **不適合**：他嘆一口氣，繼續趴著。 |

這個案件要讓學生看到：同一句「換個角度想」，在對方還很激動時沒用，平靜一點後很有用。

解鎖技能：**換個角度**

> **米亞**：卡住的時候，換個方向看。擋住你的東西，換個角度可能變成墊腳石。

## 案件 3：走廊「哭哭葵」

**委託單**：五年級走廊，有人在喊別人的綽號。

### 線索

| 線索 | 版本 A | 版本 B |
|---|---|---|
| 表情 | 臉很紅，眼睛瞪著阿凱和阿傑 | 低著頭看不到臉，耳朵紅紅的 |
| 身體 | 水壺握得很緊，往阿凱他們走過去 | 躲到洗手台旁邊，水一直開著，洗手洗了很久 |
| 話語 | 「再叫一次試試看！」 | 「沒事啦，他們在開玩笑。」 |
| 情境 | 公布欄上週比賽的照片，小葵哭的那張被人用筆畫了很多眼淚 | 同左 |
| 情境 | 阿凱和阿傑在旁邊笑：「哭哭葵、哭哭葵！」 | 同左 |

### 命名

這一案兩個版本的答案不同，是本章的重點。

- 版本 A：最貼切 **被冒犯**，也算對 **生氣**，強度 5
- 版本 B：最貼切 **丟臉**，也算對 **難過**，強度 4

版本 B 選「生氣」時，小葵會說：「我沒有生氣……我只是不想被大家看到。」

> **米亞**（結案時）：一樣是被取綽號，有人會氣到想衝過去，有人會想躲起來。看到的不一樣，因為心裡的感覺不一樣。

### 陪伴

| 選項 | 方法 | 版本 A | 版本 B |
|---|---|---|---|
| 「我陪你去跟老師說照片的事。」 | 找信任的大人 | **很適合**：她停下腳步，把水壺放下。老師把照片拿下來了。 | **很適合**：她猶豫了一下：「會不會被說告狀？」最後還是點頭。老師把照片拿下來了。 |
| 「你看起來很生氣，對不對？」 | 說出感受 | **很適合**：「對！很氣！」她說完，手鬆開了。 | **不適合**：「我沒有生氣。」她把頭壓得更低。 |
| 「不要理他們就好了。」 | 硬吞下去 | **不適合**：「為什麼是我要忍？」 | **還可以**：她鬆了一口氣跟你走開，但照片還貼在公布欄上。 |
| 「走，我們去罵回去！」 | 發洩 | **不適合**：三個人在走廊吵起來，被糾察隊記了名字。 | **不適合**：她搖頭往後退：「我不要。」 |

這是霸凌情境，所以「找信任的大人」兩個版本都很適合。學生要學的是：遇到被取笑，找大人不是告狀。

解鎖技能：**說出來**

> **米亞**：說出「我很生氣」「我覺得很丟臉」，感覺會小一點。這不是我說的，是科學家量出來的。

## 終章：主角自己的情緒（闖關，約 4 分鐘）

**觸發劇情**（回社辦的路上）：

> 你抱著寫滿線索的偵探筆記走回社辦。轉角有人跑過來撞到你，筆記掉進水桶，字全部糊掉了。
> 撞你的人頭也沒回就跑了。走廊另一頭有人在笑。
> 你感覺臉發燙，手握緊了。
> **米亞**：等等！你的情緒冒出來了。這次，換你當自己的偵探。

畫面切進橫向卷軸關卡。

### 闖關規則

| 項目 | 內容 |
|---|---|
| 目標 | 從走廊左邊走到社辦門口（右邊） |
| 操作 | 左右移動、跳躍、4 個技能按鈕（只有解鎖的技能能用） |
| 情緒條 | 碰到怪物情緒條會上升；滿了不會死掉，畫面會晃一下，回到上一個檢查點，米亞給一句提示 |
| 生氣怪 | 紅色果凍方塊。你一靠近就膨脹，硬撞會被彈開，而且情緒條上升更多。用**暫停**（站著不動 2 秒）或**深呼吸**，它會縮小變粉紅色，可以直接走過去 |
| 挫折怪 | 灰紫色毛線球，打結後擋住整條路，跳不過去。用**換個角度**，毛線鬆開變成一座軟軟的橋 |
| 說出來 | 畫面暗下來的區段，用「說出來」照亮，看見隱藏的平台 |
| 長度 | 3 個區段，各約 1 分鐘：生氣怪 2 隻 → 暗區＋挫折怪 1 隻 → 生氣怪和挫折怪一起 |

**提示句**（情緒條滿時，依卡住的地方給）：

- 卡在生氣怪：「硬撞只會讓它更大。試試看先停下來？」
- 卡在挫折怪：「跳不過去，就換個角度。」
- 卡在暗區：「看不見路的時候，把感覺說出來。」

**通關劇情**：

> 你走到社辦門口，發現自己的手已經放開了。
> 你在新的一頁寫下：「被撞的時候，我很生氣。後來發現，其實也很丟臉。」
> **米亞**：歡迎正式加入偵探社。

### 偵探評語

不打分數、不排名。依三個數據各給一句：

| 數據 | 條件 | 評語 |
|---|---|---|
| 平均找到的線索種類 | 4 種 | 你把四種線索都找齊了，連周圍的小細節都沒漏掉。 |
| | 3 種 | 你很會觀察，下次可以多看看周圍發生了什麼事。 |
| | 2 種 | 你找到線索就急著判斷。多看一眼，常常會發現不一樣的答案。 |
| 命名 | 都選到最貼切的詞 | 你說得出很細的情緒，不只是「生氣」兩個字。 |
| | 有用到「也算對」的詞 | 你抓到了大方向。生氣底下，常常還藏著別的感覺。 |
| 陪伴 | 「很適合」有 2 個以上 | 你看得出對方現在需要什麼，不是每次都用同一招。 |
| | 「很適合」少於 2 個 | 同一個方法，有時有用、有時沒用。差別在對方當下有多激動。 |
