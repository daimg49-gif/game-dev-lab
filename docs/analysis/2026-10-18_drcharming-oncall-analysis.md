## 一、它是什麼

俯視地圖的值班生存遊戲。玩家是內科病房的 PGY（畢業後一般醫學訓練醫師），從 17:00 接班值到隔天 08:00，要一邊處理病人和護理師的電話，一邊顧好自己的精力、肚子、尿意 ✅。

| 項目 | 內容 |
|---|---|
| 作者 | 首頁署名「嘉義長庚內科部 R3 張家明」✅ |
| 所屬網站 | 「我就怕被罵嘛」內科值班模擬器，對象是醫學生、PGY、住院醫師 ✅ |
| 兩種玩法 | 對話版（打字問診、開醫囑，AI 護理師回應，最後總醫師講評）＋遊戲版（本作）✅ |
| 遊戲版分兩級 | 民眾體驗版（免費、免下載，教急救觀念）／專業醫師 Pro 版（自由輸入醫囑，接對話版的臨床引擎和 AI 護理師）✅ |

## 二、故事設計

沒有長篇劇情。故事是「一個晚上的時間表＋隨時會響的電話」組成的。

### 1. 用時間表當骨架

| 時刻 | 頁面標示 |
|---|---|
| 17:00 | 接班 |
| 18:00 | 晚餐 |
| 23:00 | 熄燈 |
| 04:00 | 最難熬 |
| 08:00 | 交班 |

這五個時間點在開場就攤給玩家看 ✅，玩家一開始就知道「今晚會怎麼過」。04:00 只寫「最難熬」三個字，沒有說明會發生什麼，留了懸念。

結算畫面寫「07:30 · 交班」，跟時間表的 08:00 對不上 ✅。可能是提前結算，也可能是文案沒同步。

### 2. 交班單當教學

開場是一張交班單：總醫師林醫師 R3，分機 3301。「先自己看過病人，處理不來再打給總值，不要等到病人變差。」✅

規則用劇中文件講出來，不另外跳教學視窗。這句話同時是操作提示，也是這個職業的真實守則。

### 3. 電話是主要事件來源

電話響的時候，玩家有三種回法 ✅：

- **去看**：走到床邊處理
- **電話交代**：不過去，用電話處理
- **繼續睡**：不理它

在吃飯或睡覺時響，按鈕文字會跟著情境變 ✅：

| 情境 | 選項文字 |
|---|---|
| 吃到一半 | 「放下筷子就去」／「再扒兩口」 |
| 睡覺中 | 「起床去看」／「繼續睡」 |
| 總值打來 | 「回覆總值」 |

「扒兩口可以多回一點精力，但護理師會等比較久」✅。每個選項都有代價，沒有標準答案。

### 4. 總醫師：先道歉才給提示

處理不好時總醫師會生氣，規則寫明「第一步先道歉，總值才會給你下一步的提示」✅。玩家角色有一張「被罵」表情（scolded）✅。

這是整款遊戲最有意思的社交設計：求助有門檻，而且門檻是人際上的，不是數值。

### 5. 結局

| 結局 | 條件 |
|---|---|
| 你撐過今晚了 | 撐到交班，顯示今晚分數和「總值留言」✅ |
| 累倒 | 精力歸零，今晚直接結束 ✅ |
| 病人惡化 | 病人放太久會變差，護理師會再打來 ✅；嚴重到什麼程度會結束 ❓ |

結算後可以「再值一晚」、分享圖卡、複製文字、下載圖片 ✅。

## 四、程式概念

### 從圖片檔名看出的美術管線 ✅

角色圖都放在 `/assets/game/char/`，命名規則是 **角色_變體_表情.png**：

```
nurse_neutral / nurse_panic / nurse_shocked
pgy_m_neutral / pgy_m_sleepy / pgy_m_nervous / pgy_m_eating / pgy_m_scolded / pgy_m_confident
pgy_f_neutral
chief_angry
```

護理師 3 張、男主角 6 張、女主角目前只看到 1 張、總醫師 1 張。程式只要知道「誰、現在什麼情緒」，就能組出檔名換圖 🔍。女主角表情少很多，可能還沒畫完，或程式找不到圖時退回 neutral 🔍。

### 推測的架構 🔍

```
時間迴圈（遊戲內時鐘，睡覺時加速、P 鍵暫停）
  ├─ 身體三條隨時間下降（精力、肚子、尿意）
  ├─ 每床病人有一個惡化計時器，放著不管就往下掉
  ├─ 事件排程：到點或病人惡化 → 電話響，跳出情境化選項
  ├─ 抽血：下單時記時間，+30 分鐘後推播結果
  └─ 精力 = 0 → 結束；時鐘到交班 → 結算
          ↓
床邊互動（E 進入）
  ├─ 民眾版：寫好的選項 🔍
  └─ Pro 版：自由輸入醫囑 → 送進「對話版臨床引擎」（LLM）判讀 🔍
          ↓
結算：分數＋總值留言（可能也由 AI 生成 🔍）→ 分享圖卡
```

「從這一床重來」代表每一床是獨立的存檔點，惡化狀態可以單獨回溯 🔍。

### 不知道的 ❓

用了哪個遊戲引擎或框架、地圖怎麼畫、病例有幾個、分數怎麼算、Pro 版的 API 金鑰是作者出還是玩家自備、尿意滿了會怎樣。

## 六、Pei 可以借用的

### 先講適用對象

內容是醫療處置和急救，Pro 版要專業知識。Pei 的學生是三到六年級，**不適合直接玩**。以下只談設計手法。

### 建議借用

1. **表情圖命名規則**：情緒偵探社、校園溫度計的角色圖一律用 `角色_表情.png`（例如 `xiaoming_angry.png`）。交給 ChatGPT 生圖時給一張表情清單，程式照檔名換圖，缺圖退回 neutral。
2. **情境化選項文字**：同一個「去處理」，在不同情境寫成不同的話（「放下筷子就去」）。學生會覺得是自己在做決定，不是在按按鈕。
3. **每個選項都有代價**：「再扒兩口」回精力但對方要等。放進校園溫度計，例如「先把作業寫完」和「先去安慰哭的同學」，兩邊都有得有失。
4. **打斷機制**：學生正在做一件事時，突然有人來找。練習的是「現在要不要停下來」，比單純選對錯更接近真實人際。
5. **求助有人際門檻**：「先道歉才給提示」可以改成「先說出你現在的感覺，輔導老師才會給建議」。這是 SEL 的核心動作，正好接得上情緒偵探社。
6. **自我照顧也是資源**：給主角一條「電量」，一直幫別人、不休息會掉到跑不動。讓資優生看到「照顧自己」不是偷懶。
7. **延遲回饋**：做了一件事，結果過一段時間才出現（例如道歉後，對方隔一節下課才回應）。練習等待和不確定。
8. **單一事件重來**：「從這一床重來」→「從這個事件重來」，學生可以只重試卡住的那一關，不用整局重玩。
9. **交班單當教學**：開場用一張劇中文件（例如「班長交接本」）講規則，不跳教學視窗。

### 建議先不要

1. **AI 自由輸入（Pro 版做法）**：學生打的字會送到外部 AI，涉及隱私和金鑰費用，也很難控制回應內容。校園遊戲維持寫好的選項。
2. **尿意這類身體需求**：國小生玩到會笑場，焦點容易跑掉。留「電量」一條就好。
3. **一晚 15 小時的時間跨度**：改成一節下課或一天上學，配合 20 分鐘一輪。
4. **累倒直接結束**：對國小生太挫折。改成「電量歸零就強制休息一回合」。
