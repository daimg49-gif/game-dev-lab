## 一、它是什麼

文字為主的人生模擬。你會隨機出生成「此刻地球上某個剛出生的嬰兒」，國家、性別、家境都不能選，從 0 歲一路活到死亡。出生地、壽命、收入、會遇到什麼事，全部按真實統計的機率抽。

| 項目 | 內容 |
|---|---|
| 開發 | 韓國開發者 Jin Hwi-eus，一個人和 AI 一起做 📰；首頁寫「營運者與 AI（Claude）一起製作」✅ |
| 上線 | 2026-10-05。從第一個提示詞到網站公開大約 4 小時，原本沒打算公開 📰 |
| 迭代速度 | 10-06 v0.4.41、10-13 v0.6.88、10-18 v0.7.53；條款頁自稱「一個人每天在做、在修」✅ |
| 平台 | 瀏覽器，免安裝、免帳號、無廣告 ✅；主機用 Cloudflare ✅ |
| 語言 | 韓、英、日、繁中、越南文 ✅；繁中版 10-15 加入 📰 |
| 一生長度 | 約 30 分鐘、1 小時、1.5 小時三種。選 1 小時，一年大約 40～60 秒 ✅ |
| 資料範圍 | 首頁寫 172 個國家與地區 ✅；早期報導寫 141 國 📰，應是後來擴充 |
| 對象 | 官方標示 15 歲以上 ✅ |
| 收費 | 人生模擬全程免費；另賣一次性 3 美元「紀念通行證」（台灣 NT$90），只解鎖做影片、相簿、紀錄書等周邊，付費不會改變人生內容 ✅ |

作者的動機是：一直好奇自己生活圈以外的人怎麼過日子，希望玩家玩完不只覺得「自己出生在好地方真幸運」，而是能尊重那些同樣無法選擇起點的人 📰。

## 二、故事設計

這款沒有編好的劇情。故事是「統計表＋玩家選擇」當場長出來的，所以每個人玩到的一生都不一樣。

### 1. 開場就把規則講成一句話

首頁開頭：此刻每秒大約有 4 個嬰兒誕生，你將成為其中一個；在哪裡出生、成為誰的孩子都無法選擇，「就像你當初一樣」✅。旁邊有兩個即時計數器：打開頁面後出生的嬰兒數、同一段時間離世的人數 ✅。

規則和主題在開場的一句話裡就講完，玩家還沒按「出生」就知道這個遊戲在問什麼。

### 2. 出生前只問三件事，而且都可以跳過

| 設定 | 選項 |
|---|---|
| 出生的世界 | 過去（指定年份，用當年統計）、現在、未來（聯合國推估）、哪個都好 ✅ |
| 出生地抽法 | 依各地每年出生人數，或依現有 80 億人口比例 ✅ |
| 一生長度 | 30 分、1 小時、1.5 小時 ✅ |
| 你實際的出生地（選填） | 選了會在結算時把這一生和你自己的人生並排比較，只存在這台裝置 ✅ |

首頁明寫「設定不用改，直接出生也沒關係」✅。按下出生後，才揭曉國家、性別、名字、父母家境 📰。

依出生人數抽，印度約 17.7%、中國 6.8%、奈及利亞 5.7%、巴基斯坦 5.2% 📰。台灣玩家多半會發現自己很難抽到台灣，這個落差本身就是體驗的一部分。

### 3. 選擇只能改變機率，改不了起點

玩家要做兩種選擇 ✅：

- **每年的重心**：讀書、工作、家庭、健康，隨時可以改
- **人生關卡的抉擇**：升學、工作、愛情、移居、治療。報導舉的例子有「就算會增加父母負擔，還要繼續念高中嗎？」、出生在北韓時問「要脫北嗎？」📰

首頁寫明：選擇會改變人生，但很難完全擺脫出生地的統計 ✅。四個狀態值的說明也照這個原則：「數值高只會提高可能性，不會決定結果」✅。

### 4. 五個年齡停下來問一個問題

5、15、30、50、70 歲時，時間會停下來問一個問題，請玩家把這個人的人生和自己的人生放在一起想，願意的話留一行字；最後還可以對這個人說一句話 ✅。報導引用的題目例子是「把這段人生和你自己的比較，你有什麼感覺？」📰

這是整款遊戲最接近「教學設計」的地方：模擬一直跑，反思被固定插在五個點。

### 5. 同一秒出生的另外四個人

你出生的那一秒，地球各處也有其他嬰兒誕生，其中 4 個人會按同樣的統計活到最後，並排在你的人生旁邊 ✅。

跟 fab24hr「六個位子看同一天」同一個方向，差別在這裡是「同一個起跑點、不同的出生地」。

### 6. 沉重的事照統計發生，但不描寫畫面

死亡、疾病、戰爭、貧窮、成癮、家暴、自殺都會按真實統計發生；遊戲不描寫場面，會一併告訴玩家可以求助的地方 ✅。過去的世界也會出現真實的戰爭與屠殺 ✅。

這一條改過一次 📰：作者原本說不放自殺，怕它看起來像躲不掉的命運，也怕正在掙扎的玩家看到；10-11 的 v0.6.36 改成加入，理由是把那些人生排除在外等於讓他們不存在。目前的設計是 10 幾歲起依國家、年齡、性別的統計發生，孤立、喪親、失業、負債會提高風險，「跟人說話」會降低風險，發生時死亡紀錄附上求助專線。

作者也刻意加了溫暖的日常，例如排燈節、齋月、聖誕節一起吃飯的場景，避免某些國家只剩下貧窮和苦難 📰。

### 7. 結束之後

| 功能 | 內容 |
|---|---|
| 人生紀錄 | 一行一年，最新的在上面，可以點一行加☆ ✅ |
| 人生地圖 | 一格＝一年，用顏色標出每一年發生什麼 ✅ |
| 存活曲線 | 同年出生的人裡還活著的比例 ✅ |
| 分享卡 | 一張卡寫名字、國家、性別、死亡年齡、病史、職業 📰，在社群上傳開 |
| 追思館 | 把走完的人生公開安放，任何人可以點蠟燭、留固定的幾句話 ✅ |
| 大家分享的人生 | 公開的人生摘要＋玩家感想，不留名字和聯絡方式 ✅ |
| 前世紀錄 | 最近 10 段人生，可以重新打開死亡紀錄和分享卡，只存在這個瀏覽器 ✅ |

10-07 單日流量是前一天的 7 倍；受訪時約 58% 的人生被玩家一路玩到最後 📰。

## 四、程式概念

### 推測的架構 🔍

首頁與條款透露三件事：一個人每天改、文字為主幾乎沒有圖、紀錄只存本機。推回去大概是這樣：

```
統計資料表（172 地 × 約 20 項指標，另有各國分性別生命表、各區死因比例）
        ↓
出生抽籤（依出生數或人口比例加權抽國家 → 抽性別、家境）
        ↓
每年一次的迴圈（tick）
  ├─ 依生命表查「這個年齡今年死亡的機率」擲骰
  ├─ 依重心與狀態值調整機率，抽今年的事件
  ├─ 到了特定年齡或條件 → 跳出抉擇卡，暫停等玩家
  ├─ 5／15／30／50／70 歲 → 跳出反思題
  └─ 寫一行人生紀錄、塗一格人生地圖
        ↓
死亡 → 依區域、年齡的死因比例抽死因 → 結算頁、分享卡
```

幾個機制的可能做法：

- **一年多長**：1 小時設定下一年 40～60 秒，代表程式用「選定時長 ÷ 當地平均壽命」算每年秒數 🔍。壽命 60 歲的國家一年 60 秒，壽命 85 歲的國家一年約 42 秒，剛好落在官方寫的範圍。
- **收入**：只給吉尼係數就能產生一整條所得分布，常見做法是假設對數常態分布，用吉尼係數換算出分散程度，再依家境抽位置 🔍。
- **狀態值影響機率**：「數值高只提高可能性」代表狀態值是乘在機率上的係數，不是門檻 🔍。
- **同一秒的 4 個人**：同一套迴圈多跑 4 次，只是不停下來問玩家，等於永遠開著「自動抉擇」🔍。

### 不知道的 ❓

用了哪些前端技術、檔案怎麼拆、事件文字是寫死的還是即時生成、有沒有自動測試、Claude 在寫程式、整理資料、寫事件文字各佔多少。

## 六、Pei 可以借用的

### 先講適用對象

官方標示 15 歲以上，教學版也只放寬到 12 歲以上。Pei 的學生是三到六年級，**不適合讓學生直接玩這款**。以下只談設計手法。

### 建議借用

1. **定點暫停反思題**：情緒偵探社每結一件案，停下來問一題「你有沒有過跟他一樣的感覺？」，可以只想不寫；要寫的話只存在本機，不送出。
2. **選擇只改機率**：狀態值用「提高可能性」的方式影響結果。很適合拿來讓資優生體會「做對選擇也可能失敗」，跟失敗博物館課程的主題接得上。
3. **同一起點並排比較**：同一節下課，4 個同學分別遇到不同的事，結算時並排顯示。跟 fab24hr 的多位子做法可以合併成一個「並排結算」元件。
4. **一格一單位的地圖**：結算時把一天畫成格子，一格一節課，用顏色標出情緒。比一段文字評語更容易看懂。
5. **教學版開關**：每款遊戲預留一個網址參數（例如 `?mode=class`），開啟後關掉不適合的內容、存檔、外部連結。跟 fab24hr 的教師頁一起放進「第六層：周邊頁」。
6. **自動模式＋倍速**：老師在台前示範時用自動模式快速跑一輪，學生再自己玩。
7. **狀態值一句話說明**：每個數值旁邊寫「它影響什麼、什麼會讓它上升」，學生不會把數值當分數。
8. **沉重內容的三條原則**：照實發生、不描寫畫面、附求助資訊。情緒偵探社的霸凌情境可以照這三條檢查一次。

### 也許可以開一款新遊戲（交 Pei 決定）

把「統計表當內容」用在數學或社會領域。例如用內政部、教育部的公開統計，做「如果你是 1950 年出生在高雄的孩子」，配合橋頭糖廠的多元資優方案；或給資優生當獨立研究的題目，讓他們自己找統計、自己定規則。

### 建議先不要

1. **付費、公開追思館、玩家發文**：要後端、要審查玩家文字，學校用不到。
2. **172 國統計資料**：整理資料的工作量很大，教學上用 1 個縣市、5～10 項指標就夠。
3. **30～90 分鐘一輪**：一節課 40 分鐘，情緒偵探社的 20 分鐘比較合適。
4. **自殺、家暴等題材**：國小對象先不放，與情緒偵探社「家庭衝突先不放」的決定一致。
